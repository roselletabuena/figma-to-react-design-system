## How to use this file

- A row is **done** when its code path and implementation date are filled in and the component follows the file structure in `.claude/rules/component-architecture.md`.
- To start a component, open its Figma link and run the `create-component` skill. The skill's "Update the Figma status tracker" step flips `todo` to `done`, fills in the code path and the `Implemented` date (YYYY-MM-DD), and updates the counts, all in the same PR as the component.
- **Primitive** rows are building blocks that sit under a larger component in Figma (for example `Pagination Page` under `Pagination`). Build them together with their parent unless they need to be exported on their own.
- Not covered here: the Foundations, Icons, Examples, Composition guide, Forms, Sections, Utilities and Component Playground pages.
